# Settings

## Feature overview

**Settings** is your personal workspace for profile information, appearance, and optional ticket preferences.

**Access:** Any signed-in user.

---

## Profile card

| Field | Editable here? |
|-------|----------------|
| Display name | No (read-only) |
| Username | No |
| Email | No |
| Role | No |
| Active status | No |
| Last updated | No |

Contact an administrator to change profile data.

If loading fails, click **Retry**.

---

## Reporting period default

Sets the default time window for dashboard-style views (e.g. Today, 7 days, 30 days).

1. Open the section.
2. Choose your preferred default.
3. Saves automatically or via save control (as shown on screen).

---

## Tickets auto-refresh

Controls how often the **ticket list** refreshes in the background.

1. Enable or disable auto-refresh.
2. Pick an interval if offered.
3. Helps stay current without manual reload.

---

## Appearance

| Option | Description |
|--------|-------------|
| **Light** | Bright theme for daytime |
| **Dark** | Reduced glare for long shifts |

Click a card to select; a checkmark shows the active theme. Preference is saved on this device.

---

## Install app (PWA)

On supported phones and browsers:

1. Open **Install app** in Settings.
2. Follow the prompt to add Samanvi to your home screen.
3. Launch like a native app.

---

## Tips

- Use **dark** theme on night shifts.
- Shorter auto-refresh uses more network—balance for your connection.
