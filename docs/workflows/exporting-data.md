# Workflow: Export data

Download master data for reporting, backups, or offline review.

---

## Where exports are available

| Area | Formats | Permission |
|------|---------|------------|
| **Masters → Service For** | Excel | View (+ export control as shown) |
| **Masters → Bus No → Normal buses** | Excel, PDF | View on bus_number |
| **Masters → Bus No → Spare tanks** | Excel, PDF | View on spare_tank |
| **Tickets** | Print single ticket | View ticket |
| **Garage job details** | PDF | View repair job |

> Garage **Reports** page may not yet offer bulk export—use job PDFs per record.

---

## Export from Service For

1. Open **Masters → Service For**.
2. Click **Export** (or Excel icon—label may vary).
3. File downloads to your browser’s download folder.
4. Open in Excel or compatible spreadsheet app.

---

## Export from Bus No

### Normal buses

1. Open **Masters → Bus No**.
2. Stay on **Normal buses** tab.
3. Choose **Export Excel** or **Export PDF**.
4. Save file when prompted.

### Spare tanks

1. Switch to **Spare tanks** tab.
2. Use **Export Excel** or **Export PDF**.

---

## Print or PDF for single records

### Ticket

1. Open **Ticket details**.
2. Click **Print**.
3. Use browser print dialog → Save as PDF if needed.

### Repair job

1. Open **Job details**.
2. Click **Download PDF**.
3. File saves with job information and parts summary.

---

## Best practices

- Export during **low-traffic** times for large bus lists.
- Store exports per your company **data policy** (do not email unencrypted if policy forbids).
- Refresh export after bulk edits in masters.

---

## Troubleshooting

| Problem | Try |
|---------|-----|
| Export button missing | Ask for view permission on that submodule |
| Empty file | Filter list first; confirm data exists |
| PDF won’t open | Update PDF reader; try Excel export instead |
