# Glossary

Plain-language definitions for terms used in Samanvi.

| Term | Meaning |
|------|---------|
| **Active (account)** | User can sign in. Inactive users cannot. |
| **Admin** | Highest access; all permissions; some screens (Board, Users) are admin-only by role. |
| **Application Access** | Area to manage login accounts and permissions. |
| **Assign / Assignment** | Giving a ticket or repair job to a specific person. |
| **Board** | Kanban view of tickets by status (admins). |
| **Bus No** | Masters page with full bus records (engine, chassis, permits, odometer). |
| **Buses** | Simpler bus list used mainly for ticket history (admin/supervisor). |
| **Category (ticket)** | Type of issue from the issue categories list. |
| **Category (garage)** | Type of repair work; often hierarchical (parent/child). |
| **Closed (ticket)** | Ticket finished; no further work expected. |
| **Closed (repair job)** | Job closed in system (may appear on records). |
| **Collection Agent** | Application user type for field collection roles. |
| **Comment** | Note on a ticket or repair job timeline (not always a status change). |
| **Completed (repair)** | Repair work finished. |
| **Created (ticket)** | New ticket, not yet assigned or started. |
| **Dashboard** | Summary screen of ticket counts and team metrics. |
| **Garage** | Module for repair jobs, parts, and repair categories. |
| **Garage Masters** | Repair categories and spare parts catalog. |
| **Helper** | Crew member type in Employees master. |
| **In Progress** | Work actively being done (ticket or repair). |
| **Issue / Ticket** | Record of a fleet problem to track and resolve. |
| **Leaf category** | Lowest-level repair category with no children—required for new jobs. |
| **Masters** | Reference data: buses, routes, crew, service types. |
| **Odometer** | Distance the bus has traveled, recorded in kilometers. |
| **Office Staff** | Garage/admin staff in Employees master. |
| **On hold (repair)** | Repair paused temporarily. |
| **Open (ticket)** | Not closed—may include several statuses. |
| **Overdue** | Past the SLA due date without resolution. |
| **Permission** | Allowed action on a module (view, create, edit, delete, etc.). |
| **Priority (P1/P2/P3)** | Urgency of a ticket; P1 most urgent. |
| **Repair job** | Garage record for work done on a bus. |
| **Repair Tracking** | List of repair jobs. |
| **Repeat job** | Follow-up repair scheduled from a previous job. |
| **Resolved** | Ticket fix completed; note usually required. |
| **Reopened** | Ticket opened again after being closed. |
| **Role** | Ticket workflow level: Admin, Supervisor, Worker, Viewer. |
| **Service For** | Master lookup describing service type for routes. |
| **Service No** | Master record for a route/service number. |
| **Severity** | Impact level: Critical, High, Medium, Low. |
| **SLA / SLA Due At** | Target date and time to resolve a ticket. |
| **Spare part** | Catalog item used on a repair job (name, price). |
| **Spare tank** | Alternate bus/tank record in Bus No masters. |
| **Supervisor** | Role with broad ticket and bus access. |
| **Timeline** | History of actions on a ticket or repair job. |
| **User type** | Business role on Application Access (Chairman, Worker, etc.). |
| **Viewer** | Read-only ticket role. |
| **Worker** | Role that works assigned tickets; limited status changes. |

## Abbreviations

| Abbreviation | Meaning |
|--------------|---------|
| **FC** | Fitness certificate (bus compliance) |
| **DL** | Driving licence (driver records) |
| **PWA** | Installable web app (Add to home screen) |
| **SLA** | Service level agreement (due date target) |
